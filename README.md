# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.

## Features
- Landing page with the company name, an About Us section and a "Get Started" button
- Plant listing grouped into three categories, six plants each, with thumbnail, name and price
- "Add to Cart" buttons that disable after use and update the cart icon count
- Shopping cart with per-plant totals, a cart total, quantity controls and delete buttons
- Checkout button ("Coming Soon") and a Continue Shopping button

## Run locally
```
npm install
npm run dev
```
